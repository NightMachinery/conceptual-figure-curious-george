# Reference images

Each design gets a reference image, generated by an image model from its `handoff-t2i.md`. The
prompt file goes in whole and unedited in both lanes; they differ only in who runs the model. The
gate and everything after it are the same.

## `user` lane (default)

Give the user the list of `handoff-t2i.md` paths and where to save each image
(`design-<x>/reference.png`). The user may supply several images per design and name the one to
use.

## `auto` lane

An *image agent* is an agent whose harness has a built-in image-generation tool. The lane needs
one; an agent without the tool cannot stand in, because a "reference" drawn with code is just an
early draft of the figure.

1. **Probe first.** Before the designers reach the gate, start one image agent with a trivial
   prompt and a save path, and ask for the tool's name, where the tool first wrote the file, and
   the pixel size of the saved copy, or a fixed `NO-IMAGE-TOOL` line. If the probe fails, fall back
   to the `user` lane and say so.
2. **Brief the image agent** once the hand-offs are approved, one agent per design or one for a
   few designs. The brief says:
   - generate with the image tool only, never with code, SVG or a plotting script;
   - read `design-<x>/handoff-t2i.md` and pass its content as the prompt, whole and unedited: no
     summary, no additions, no improvements;
   - the aspect ratio of the figure's target size, at the largest size the tool offers;
   - one image per design; on a refusal or failure retry once with the prompt unchanged, then
     report the error and go on to the next design;
   - copy the result to `design-<x>/reference.png` from wherever the tool wrote it, without
     overwriting an existing reference (`reference-2.png`), and check that the copy is a real image;
   - write nothing else, edit no hand-off, run no git command;
   - report per design: the saved path, the pixel size, and whether the image follows the
     prompt's layout.
3. **Wait for its completion notice**, armed at launch. Designers stay stopped.
4. **View every image yourself.** It is a visual target, not a source of content: misspelled or
   invented text in it is expected and no reason to regenerate, because the brief fixes every
   string. Regenerate only when the composition is unusable, such as a missing region or a layout
   unrelated to the prompt.
5. **Send each designer the go-ahead** with its image path. The designer commits the image with
   its revised brief, since the image agent does not commit.
